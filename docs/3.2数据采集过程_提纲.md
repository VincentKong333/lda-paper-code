# 3.2 数据采集过程

- **3.2.1 技术选型**：站点为 SPA，数据经 XHR JSON 接口（`/v1/threads/list/df`、`/v1/threads/content`）下发；逆向接口签名 `md5(路径+参数+密钥)` 后 Python 直连调用，无需 Selenium/浏览器渲染。
- **3.2.2 反爬策略**：列表页 ~9s、详情页 4.5–6s 随机间隔（实测 3.5s 触发 403）；固定真实浏览器 UA + 完整请求头；失败指数退避重试（≤40 次，上限 600s）；单线程顺序采集。
- **3.2.3 两阶段流程**：① 列表游标分页（`lastItem`）收集 `tid`，设 `showUnAnswer=1` 覆盖待回复样本；② 按 `tid` 抓取详情（正文、回复、回复部门、时间）；支持断点续跑。合计 3348 条（2024-08 ~ 2026-08）。
- **3.2.4 数据字段**：`tid`、标题（`subject`）、正文（`content`）、回复（`reply_content`）、回复部门（`reply_organization`）、状态（`state_info`）、留言时间（`create_date`）、回复时间（`reply_date`）、板块层级（`forum_name`/`fid`）；全量 22 字段，含派生字段回复时延 `reply_delay_days`。

> 注：实际方案为逆向 API 调用（非 Selenium 渲染）；大纲若需统一技术表述，请据实调整。
