# 第三章 数据与研究设计

## 3.1 研究数据来源
- **3.1.1 平台背景**：人民网「领导留言板」的定位与地方政府回应机制。
- **3.1.2 研究板块选取**：聚焦广州市两个核心板块——市委书记（fid=1217）、市长（fid=1218），代表性最强、留言量最大。
- **3.1.3 数据范围与规模**：采集时间窗 2024-08 至 2026-08（受站点「仅开放近两年」限制，最早 2024-08-21）；合计 **3348 条**（市委书记 1974 + 市长 1374）。

## 3.2 数据采集过程
- **3.2.1 技术选型**：站点为 SPA，数据经 XHR JSON 接口（`/v1/threads/list/df`、`/v1/threads/content`）下发；逆向接口签名 `md5(路径+参数+密钥)` 后 Python 直连调用，无需 Selenium/浏览器渲染。
- **3.2.2 反爬策略**：列表页 ~9s、详情页 4.5–6s 随机间隔（实测 3.5s 触发 403）；固定真实浏览器 UA + 完整请求头；失败指数退避重试（≤40 次，上限 600s）；单线程顺序采集。
- **3.2.3 两阶段流程**：① 列表游标分页（`lastItem`）收集 `tid`，设 `showUnAnswer=1` 覆盖待回复样本；② 按 `tid` 抓取详情（正文、回复、回复部门、时间）；支持断点续跑。
- **3.2.4 数据字段定义**：`tid`、标题、正文、回复、回复部门、状态、留言时间、回复时间、板块层级等（全量 22 字段，含派生字段回复时延 `reply_delay_days`）。

## 3.3 数据清洗与预处理
- **3.3.1 文本清洗**：去除 HTML 标签、特殊符号、空白与广告噪声；合并标题与正文用于主题建模。
- **3.3.2 中文分词与去停用词**：采用 jieba 分词，加载停用词表（含政务高频虚词），保留名词性实词。
- **3.3.3 回复时延计算**：由留言时间（`create_date`）与回复时间（`reply_date`）相减得到 `reply_delay_days`（单位：天），仅对「已办理/有回复」样本计算。
- **3.3.4 缺失值与样本筛选**：剔除正文缺失记录；区分「全样本（3348）」与「有回复子样本（2657）」两条分析线。

## 3.4 变量定义与研究样本
- **3.4.1 被解释变量**：回复时延 `reply_delay_days`（天）。
- **3.4.2 解释/分组变量**：板块（市委书记/市长）、留言类型 `type_name`、领域 `domain_name`、办理状态 `state_info`、满意度 `satisfaction`。
- **3.4.3 研究样本说明**：描述性统计基于全样本；回复时延与主题—回应关联分析基于有回复子样本。

## 3.5 研究设计与方法
- **3.5.1 LDA 主题模型**：以留言正文为语料构建文档—词项矩阵；以困惑度（Perplexity）与主题一致性（Coherence）确定最优主题数 K；输出各主题高频词与主题强度。
- **3.5.2 回复时延分析**：对有回复样本做描述性统计（均值/中位数/分位数）与时延区间分布；按板块、领域、类型分组对比，识别回应效率差异。
- **3.5.3 模型评价标准**：LDA 取 coherence 最高对应的 K；时延分析辅以分布检验与分组差异。

## 3.6 描述性统计（数据概览）
- **3.6.1 办理状态分布**：已办理 79.5%、待回复 18.2%、办理中 2.3%。
- **3.6.2 回复率**：79.4%（2657 条有官方回复）。
- **3.6.3 回复时延分布**：有效样本 2657 条；均值 67.0 天、中位数 58.65 天、P90=124.14 天；约 80% 回复集中在 15–90 天。
